Pins the iOS and Android native SDKs exactly to 4.10.0.

No JavaScript / TypeScript API changes. The new steps below run inside `startVerification()` / `startVerificationWithWorkflow()` and return the same `VerificationResult`.

- Both platforms: automatic capture is available in every variant, powered by Didit's own lightweight detectors. TensorFlow Lite on iOS and MediaPipe on Android are removed. The `autodetection` variant is deprecated and identical to `core`, and the Android `didit-sdk-autodetection-play` artifact is no longer published.
- Both platforms: Bank verification step. No setup. The native SDKs open the bank's page (for Stripe, Didit's hosted Stripe page) in the system browser.
- Both platforms: Location verification step.
  - iOS: Location is opt-in through complete Location variants (`DiditSDK/Core-Location`, `DiditSDK/NFC-Location`, `DiditSDK/All-Location`, and the SwiftPM products `DiditSDKCoreLocation`, `DiditSDKNFCLocation`, `DiditSDKLocation`). Set `$DiditSdkIosLocationEnabled = true` (or `iosLocationEnabled: true` in the Expo plugin) and this package selects the matching variant. CocoaPods and SwiftPM are both supported. The separate `DiditSDK/Location` add-on is no longer used.
  - Android: `didit-sdk-core` declares `ACCESS_FINE_LOCATION` and `ACCESS_COARSE_LOCATION`. Remove them with `tools:node="remove"` if your app never runs the step.
- Both platforms: electronic signature step (Sign documents).
- Both platforms: biometric consent screen when Didit's backend requires it for the workflow.
- Both platforms: a "No camera found" screen with a Copy link action to continue on another device.
- Both platforms: verification steps the installed SDK does not support show update-app guidance and return a failed result instead of stalling.
- Android: active liveness recovers after an interrupted or failed attempt.
- iOS: smaller framework, with translations moved out of the binary.
- Android toolchain: native 4.10.0 requires Kotlin 2.1.10+, Android Gradle Plugin 8.6.0+, Gradle 8.7+ and JDK 17. The wrapper's default Kotlin version is now 2.1.20.
- Development builds: the temporary native source pin used during development is removed. The package resolves released native 4.10.0 binaries only.
