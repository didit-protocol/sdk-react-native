Wrapper-only patch: the native iOS and Android SDKs stay pinned exactly to 4.15.1.
No JavaScript / TypeScript API changes.

- Android: the package now adds Didit's Maven repository to the app's build itself, so a React Native app needs no Gradle change to resolve the Didit SDK. On a new React Native 0.88 app, following the README (the Didit repository in `settings.gradle`) failed with `Could not find me.didit:didit-sdk:4.15.1`, because React Native's Gradle plugin declares repositories on every project and Gradle then ignores the ones an app lists in `settings.gradle`. `android/build.gradle` now adds the repository, still scoped to the `me.didit` group, to every project of the build. The README no longer asks for the `settings.gradle` entry.
