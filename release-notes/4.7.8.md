Keeps both native SDK pins at 4.7.6. No integration API changes are required.

- Fixes a callback leak in `submitTransaction`. A transaction that came back with a `verification_session` action - the one your app launches itself - kept its `onTransactionUpdated` callback, and everything that callback captured, for the life of the JavaScript runtime. Repeated submissions accumulated them even after the verification finished and the screen unmounted. The callback is now released unless the action is `wallet_ownership`, the only one the native SDKs launch and report back on. Reported in #50, thanks @anxkhn.
