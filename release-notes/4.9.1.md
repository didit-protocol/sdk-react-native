Pins the iOS and Android native SDKs exactly to 4.9.1.

- Both platforms: the document and proof of address country pickers open on the country detected from the user's IP address. When that lookup finished after the screen appeared, they used to stay on the first country in the list (Afghanistan); they now switch to the detected country, without overriding a country set in the session or one the user picked.
- Android: a questionnaire's section header and fields are shown in the SDK language. A questionnaire authored in one language with translations no longer shows its default-language header above translated fields.
- Android: NFC passport scanning no longer crashes with a missing `org.jmrtd.BACKey` class in the full (`all`) variant.
- Both platforms: improved Russian and Kyrgyz verification copy.
